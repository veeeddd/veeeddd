## 🚀 Featured Projects
 
### 📈 AlphaPulse — Real-Time Financial Sentiment Engine
> *Turning a daily flood of financial news into a clean signal.*
 
- Autonomous, FastAPI-ready modular backend that scrapes and scores **1,000+ financial articles a day** with **FinBERT**, with sub-second inference per article
- Self-healing ingestion loops (request jitter and source rotation) sustaining **>99.5% uptime** and cutting pipeline failures by **~80%** versus naive polling
- **DuckDB** analytical layer for fast 30-day rolling sentiment-trend queries, with no dedicated data warehouse needed
- Scheduled scraping and scoring runs automated with **GitHub Actions**, so the dataset stays fresh without manual work
`Python` `FinBERT` `DuckDB` `BeautifulSoup4` `GitHub Actions`
 
---
 
### 🏥 [AETHER](https://github.com/veeeddd/AETHER) — Federated Learning Medical Diagnosis
> *Train across hospitals without a single patient record leaving the building.*
 
- Privacy-preserving federated learning system (**Flower + PyTorch**) across **4 simulated hospital nodes** using decentralized FedAvg aggregation
- Converges within **5% of centralized-training accuracy** with **zero raw patient data transfer**
- **Gradio** clinical interface that runs diagnosis predictions on the aggregated global model, turning the research pipeline into an end-to-end demo
`Python` `PyTorch` `Transformers` `Flower` `OpenCV` `Gradio`
 
---
 
### 🧠 [DeepRead CLI](https://github.com/veeeddd/DeepRead-CLI) — Local RAG Engine
> *Chat with your PDFs, 100% offline. No API keys. No data leaks.*
 
A private, local-first Retrieval-Augmented Generation engine built on **Llama 3 (GGUF quantized)**, **ChromaDB**, **LangChain** and **HuggingFace Sentence-Transformers**. Point it at any PDF, ask questions in plain English, and everything runs on your CPU.
 
`Python` `LangChain` `ChromaDB` `Llama 3` `RAG`
