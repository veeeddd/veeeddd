## 🚀 Featured Projects

### 🧠 [DeepRead CLI](https://github.com/veeeddd/DeepRead-CLI) — Local RAG Engine
> Chat with your PDFs, 100% offline. No API keys. No data leaks.

Built a private, local-first Retrieval-Augmented Generation engine using **Llama 3 (GGUF quantized)**, **ChromaDB**, **LangChain**, and **HuggingFace Sentence-Transformers**. Point it at any PDF and ask questions in plain English — everything runs on your CPU.

`Python` `LangChain` `ChromaDB` `Llama 3` `RAG` `Local LLM`

---

### 🏥 [AETHER Diagnostics](https://github.com/veeeddd/AETHER) — Medical Vision AI
> Autonomous X-ray analysis with no cloud dependency.

An autonomous medical intelligence system using **Moondream2 VLM** to detect fractures, pulmonary anomalies, and foreign objects in X-rays — fully local, generating structured PDF diagnostic reports automatically. Built under the **Nocteon Inc.** umbrella project.

`Python` `Moondream2` `VLM` `Medical AI` `FPDF` `Computer Vision`

---

### 📡 [Nectar Network Tool](https://github.com/veeeddd/Nectar-Network-Tool) — Android Intelligence Dashboard
> Real-time network latency monitor + IP intelligence for Android.

`Kotlin` `Android` `Network Monitoring`
